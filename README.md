# Event-Driven Commerce

A microservices-based e-commerce platform built around event-driven architecture.

## Structure

- `services/` — individual microservices
- `shared/` — shared libraries/types used across services
- `infrastructure/` — infra-as-code, deployment configs
- `docs/` — architecture and design documentation
- `tests/` — cross-service/integration tests

## Getting Started

See `Makefile` for common commands and `docker-compose.yml` for local environment setup.
